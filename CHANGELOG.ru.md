# История изменений

[English](CHANGELOG.md) · **Русский**

## 0.2.0-beta.13 — эффекты Minecraft и локальные задержки

- Взрывы и привязанные эффекты создаются в Minecraft и за пределами видимости RTS. Правила тумана в RTS сохранены.
- Контур стартовой площадки поднят над поверхностью: раньше он уходил внутрь земли.
- Убраны повторные запросы света для частей одного юнита и поиск границ на каждой вершине. Буфер захвата интерфейса переиспользуется.
- Добавлен отчёт о задержке: кадры Minecraft, обработка клика, локальная доставка ввода и работа native-движка.

## 0.2.0-beta.12 — настройка, эффекты и ЭМИ

- Поиск обеих игр в общей папке; безопасный выбор папки при пустом поле.
- Контур площадки для расчистки возле стартового маркера. «Случайная сторона» переименована в «Случайный генерал».
- Сцена обновляется между тиками Minecraft; эффекты с повторно используемыми ID больше не интерполируются. Освещение зданий берётся над землёй, в режиме Minecraft постройки видны вне тумана RTS.
- Ракеты детонируют при столкновении с импортированными стенами Minecraft. Сохраняется оригинальный урон по площади.
- Громкость играющей музыки восстанавливается после F8 и загрузки карты.
- Оригинальная ЭМИ действует на мобов и редстоун. Отдельные правила для техники, мобов и механизмов; после импульса работа восстанавливается.
- При наличии Modern UI: компактная таблица участников, выбор в ячейках, превью карты и отдельная кнопка старта. Без него остаются стандартные элементы Minecraft.

## 0.2.0-beta.11 — рельеф и навигация

- Исправлено освобождение занятых клеток при отрицательных координатах и смене размеров пехоты. Движущиеся наземные юниты держатся импортированной поверхности.
- По умолчанию блоки разрушаются только принудительной атакой. Урон юнитам остаётся оригинальным; снаряды сохраняют намерение выстрела.
- Правила разделены на «Бой», «Мобы» и «Мир». Право изменения проверяет сервер.
- Добавлена расчистка стартовых площадок с предварительной защитой контейнеров и ограничением правок за тик.
- Камера при старте смотрит к ближайшему противнику. В портрете командного центра показан оригинальный значок генерала.

## 0.2.0-beta.10 — возврат из Minecraft

- F8 отключает и восстанавливает штатный ввод Generals, сбрасывая залипшие модификаторы, режим точек маршрута и захват мыши. Симуляция продолжает работать.
- Плашка владельца заменена штатной подсказкой Generals: название юнита, имя игрока, оригинальный шрифт и цвет армии.
- После ошибки компиляции сохраняются уже пересобранные native-объекты; простой Gradle-демона ограничен минутой.

## 0.2.0-beta.9 — эффекты и выбор целей

- Исправлен цвет частиц в новых версиях Minecraft: отдельные шейдеры без освещения мира. Восстановлена проверка глубины частиц по умолчанию на 26.2/26.3.
- Слизни и другие враждебные мобы определяются через интерфейс Enemy. Ракетчики в Humvee автоматически стреляют по ним; нейтральные мобы сохраняют прежнее поведение.
- При наведении показан владелец армии. Постоянная плашка F8 убрана.
- Проверки переиспользуют профили и миры без резервных копий; завершённые тестовые сессии удаляются. Добавлен монитор задержки без записи файлов.

## 0.2.0-beta.8 — стабильность и сборка

- Ограничен объём поиска пути по частично загруженной местности с сохранением ближайшего доступного маршрута. Убраны повторные проверки, из-за которых NPC задерживал всех клиентов.
- Перед нативной компиляцией шейдеров в 26.3 подготавливаются страницы стека Windows-потока для Java-обработчика include.
- Исправлен порядок вершин после преобразования координат: здания в новых Minecraft больше не освещаются с обратной стороны.
- Добавлены README на двух языках, полная сборка через Make и черновики GitHub-релизов по тегу для всех профилей.
- Проверка готового JAR всегда запускает свежий клиент, а не использует результат из кэша.
- Добавлены длительные проверки NPC/задержки и регрессия недоступного пути. Тестовые драйверы не входят в JAR игрока.

## 0.2.0-beta.7 — новые версии Minecraft

- Добавлены профили 1.21.11, 26.1, 26.1.1, 26.1.2, 26.2 и 26.3. Поддержка 1.21.4 сохранена; по умолчанию выбрана 26.3.
- Адаптированы ввод, камера, модели, mipmap, туман, сущности, загрузка чанков и данные мира. Движение и интерфейсы проверены в игре.
- Переносятся прежние маркеры, заметки, правила и остаток ресурсов при смене формата SavedData. Старые файлы сохраняются; новые данные имеют приоритет.
- Цель нажатой команды мыши сохраняется на весь кадр ввода, включая цель земли с ID 0.
- Все профили собираются из общего кода и последовательных адаптеров; пакеты отдельные, движок общий.
- Remap исходников зависимостей отключён для обычной сборки; его можно включить для IDE.

## 0.2.0-beta.6 — кандидат в релиз

- В карточке маркера собраны имя, заметка, армия, карта, телепорт и удаление с подтверждением. Для дальнего телепорта чанки готовятся асинхронно.
- Выбор игры сразу переключает профиль; обновление и редактирование разделены. Для пропавшей папки доступны исправление пути и удаление подключения.
- Добавлены цвет NPC, понятные кнопки позиций/ресурсов и правила в комнате. Сокращены подписи, гайд первого запуска можно повторить.
- Восстановлен слой логотипов командных центров из второй текстуры WW3D.
- Окно сетевой доставки отделено от очереди выполнения сервера. Два клиента проверяются с 0/100/300 мс RTT, колебаниями и восстановлением.
- Восстановлен Unix Gradle wrapper для Linux CI. Старые заметки разработки убраны из публичной документации.
- Этот выпуск рассчитан на 1.21.4; перенос на 1.21.11/26.x в нём ещё не завершён.

## 0.2.0-beta.5 — развитие NPC и карты

- Исправлены выбор нужных зданий NPC и размещение склада; планы учитывают высоту земли. Поиск ресурсов охватывает старты NPC.
- Здания, обломки и утиль следуют за изменением высоты земли.
- Исправлены UV высоких маркеров, захватывавшие чужие текстуры атласа.
- Карта ресурсов показывает только маркеры; добавлены перетаскивание, масштаб, направление игрока и центрирование.
- Добавлены поиск маркеров по расстоянию, показ на карте и безопасный телепорт с серверной проверкой прав.
- F8 переключает только запущенный матч. Унифицированы случайные/автоматические значения и строки участников.
- Обновление профиля и перенос фракций старой ROTR доступны из Minecraft.

## 0.2.0-beta.4 — Minecraft 1.21.4

- Сервер ограничивает очередь подтверждённых кадров самым медленным участником и не накапливает отставание после задержки доставки. CRC проверяется по отдельным контрольным кадрам; данные местности сжимаются, неизменившаяся миникарта не пересылается.
- Одиночная сетевая схватка с NPC использует один серверный процесс Generals; отдельная локальная копия симуляции больше не нужна. Несколько игроков сохраняют общую серверную последовательность команд.
- Исправлены запоздавшие пакеты завершённой схватки при переходе в новую комнату.
- Убраны постоянные выделения больших буферов интерфейса и временных векторов на каждую вершину моделей.
- TNT повреждает большие здания у стены, а коллизия прямоугольных зданий учитывает их форму и поворот.
- Частицы уничтоженной техники видны в обычном Minecraft и ориентируются по его камере.
- У игрока и NPC одинаковый порядок полей; карты стартов и складов разделены. Маркеры получили значки, флаги и цветные лучи в мире.
- Подключение установленной ROTR распознаёт выключенные архивы её лаунчера в приватном профиле. Названия фракций берутся из самой игры, включая замену исходных генералов новыми сторонами.
- Клавиатурные команды RTS обрабатывает выбранная Generals. В настройках Minecraft остаются клавиши переключения, меню и кнопки мыши.
- Музыка Minecraft не накладывается на музыку работающей Generals; после завершения RTS возвращается обычная музыка. Настройки громкости сохраняются.
- RTS-клавиши больше не перехватывают ходьбу, атаку и использование предметов в обычном Minecraft. Настройки переключения и мыши остаются в стандартном меню управления.
- Исправлено падение серверной копии при спутниковой разведке; графическое окно Generals работает скрыто.
- Поиск пути различает допустимый выход из ямы и высокую стену рядом; движение по обычным ступеням не наносит ложный урон от невидимого тела.
- Повторы старого маршрута строителя не перебивают строительство и ремонт. Обычные мобы учитывают здания при прокладке пути.
- Выбор нового моба получает приоритет загрузки, исходный клик сохраняется до появления цели. Двойной клик устойчивее к небольшому смещению курсора на том же юните.
- Опыт генерала за настоящие убийства мобов и победа по основным зданиям вынесены в правила мира; оба параметра можно отключить.
- Подтверждения инструментов творчества показываются в меню. Экспортируются исходные сегментированные лазерные лучи.

## 0.2.0-beta.3 — Minecraft 1.21.4

- Исправлено воспроизведённое падение Humvee/группового поиска пути при пересечении края исходной карты.
- Изменения Minecraft-мира ожидают окончания загрузки карты Generals.
- Сохраняется исходная точка движения за пределами загруженной местности; загрузка маршрута ускоряет повтор пути, а «Стоп» отменяет его.
- Закрытие остановленного движка открывает экран восстановления и возвращает обычное управление Minecraft.
- Явная кнопка возврата в Minecraft рядом с текущей клавишей переключения.
- Изнутри базы обычный прицел больше не выбирает её невидимое тело вместо блоков. Тела Generals больше не толкают персонажа и не применяют Minecraft mob-cramming.
- Раздел «Мои игры»: выбор, добавление, редактирование и удаление подключений; ошибочная проверка сохраняет рабочий профиль.
- Убрано непропорциональное Minecraft-пламя вокруг невидимых коллизий; реальный урон огня сохранён.
- Автотесты используют отдельные каталоги; отсутствие исключённого из релиза тестового драйвера корректно обрабатывается при его вызове.
- В ручной сборке Actions можно выбрать уже поддерживаемую версию Minecraft или все профили.

## 0.2.0-beta.2 — Minecraft 1.21.4

- Плюс рядом с подключённой игрой; сторона и цвет выбираются при запуске, есть случайный вариант.
- Общий список игроков и NPC, уникальные цвета, выбор случайной команды, сложность компьютера и карта стартовых маркеров; ПКМ листает команду/сложность назад.
- RU/EN по языку Minecraft, сообщения сервера переводятся на клиенте, ошибки видны поверх меню.
- Основные RTS-клавиши и мышь в обычных настройках управления; справка показывает текущие назначения.
- Отдельная вкладка Generals с маркерами; инструменты отладки оформлены как локальное творческое меню.
- Иконка выбранного моба без подписи и чисел здоровья; обычная атака по нейтральному мобу без Ctrl.
- Траектория оружия учитывает реальные высоты Minecraft; добавлены настройки радиуса/пробития блоков.
- Столкновения мобов с широкими зданиями; уничтоженные нефтяные вышки не возрождаются из маркера.

## 0.2.0-beta.1 — Minecraft 1.21.4

- Обычная установка одного JAR в Fabric: движок и Fabric API включены в мод. Отдельного установщика и сборки на компьютере игрока больше нет.
- Упрощённое подключение установленной Zero Hour, отдельные параметры для модификаций, основной запуск и настройки из меню Minecraft.
- Правила мира: разрушение блоков оружием, поджигание блоков, атаки монстров на армию, ответ нейтральных мобов и урон от окружающей среды.
- Генерация ресурсов по seed или ручная расстановка маркерами; новый блок-маркер SupplyDock, сохранение его остатка ресурсов и удаление вместе с маркером.
- В релизный JAR не входят прежняя Java-симуляция, тестовые драйверы, установщик и оригинальные игровые ассеты.
- Профили версий Minecraft, сборка JAR/движка в GitHub Actions, аудит релизного файла, SHA256 и архив соответствующих исходников.
- Проверка готового JAR в обычном окружении Fabric отделена от среды разработки; тестовый драйвер поставляется только локально для QA.

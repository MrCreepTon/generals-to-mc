# Управление

[English](CONTROLS.md) · **Русский**

Откройте **Generals** из главного меню или меню паузы Minecraft. Во время матча **F8** возвращает ходьбу и взаимодействие с блоками; схватка продолжается. Текущая клавиша указана в настройках управления Minecraft.

| По умолчанию | Действие |
| --- | --- |
| F8 | Minecraft / RTS; работает только после начала матча |
| F9 | Меню Generals; камера остаётся в RTS |
| ЛКМ | Выбор или контекстная команда: идти, атаковать, чинить, войти в транспорт |
| Рамка ЛКМ / двойной клик | Группа / одинаковые юниты по правилам Generals |
| Короткий ПКМ | Отмена или снятие выбора |
| Удержание ПКМ | Прокрутка камеры |
| Стрелки / край экрана | Движение камеры |
| Колесо | Масштаб |
| Средняя кнопка + движение | Поворот камеры |
| Ctrl + ЛКМ | Принудительный огонь |
| S | Остановить выбранные юниты |
| Удержание ЛКМ при установке | Повернуть призрак здания |
| Ctrl + цифра / цифра | Создать / выбрать контрольную группу |

Клавиши режима, меню и кнопки мыши меняются в **Настройки Minecraft → Управление → Generals**. Клавиатурные команды RTS берутся из CommandMap и горячих клавиш выбранной игры, включая изменения модификации. Они перехватывают ввод только в RTS; после переключения обратно работают обычная ходьба и взаимодействие Minecraft.

## Звук и правила

Ползунки Minecraft задают общую громкость, музыку, блоки (эффекты) и голос (реплики). Пока Generals работает со звуком, фоновая музыка Minecraft приостановлена, в том числе после F8 и в меню. Она возвращается при завершении матча или остановке движка.

Откройте **Generals → Мир и маркеры → Правила** или **Параметры → Правила** в комнате. Сначала видны разрушения, ресурсы, стартовые площадки и победа. **Дополнительно…** открывает разделы «Бой», «Мобы», «Мир» и «ЭМИ». Правила меняет только хозяин мира. На выделенном сервере до создания комнаты их задаёт оператор, затем её хост с правами оператора. По умолчанию блоки разрушают Ctrl-атака и супероружие: обычные выстрелы наносят урон без воронок. **Стартовые площадки → Расчистить** выравнивает и освобождает старты перед матчем; контейнеры и защищённые блоки останавливают расчистку. Опыт начисляется за настоящие убийства мобов армией. При включённой победе по зданиям потеря всех основных зданий выводит армию из схватки; оставшийся союз побеждает. В режиме **Свободная игра** такого условия нет.

**Правила → Дополнительно… → ЭМИ** отдельно включает действие на технику, мобов и редстоун. Техника подчиняется штатным правилам оружия Generals. В Minecraft импульс временно останавливает ИИ мобов и гасит стандартные сигналы редстоуна. Блоки остаются на месте; постоянный NoAI не записывается. Механизмы сторонних модов могут использовать другие сигналы.

**Правила → Дополнительно… → Мобы** включает микроволновое оглушение и отражение стрел мобов полем ECM. Оглушение временное, здоровье не снимается. Эти настройки не меняют действие оружия на технику Generals.

## Комната и маркеры

**Готов** подтверждает выбор. Когда готовы все игроки, матч начинается. Изменение настроек, позиций или состава сбрасывает готовность. **Чат** или **T** открывает чат комнаты; Esc возвращает в лобби.

Комната использует таблицу Generals: генерал, цвет, команда и старт находятся в одной строке. Выбор открывается возле ячейки; сложность и удаление NPC открываются по его имени. Справа показана карта, на небольшом экране она открывается кнопкой **Карта**. Тёмная тема встроена в мод. С Modern UI на поддерживаемых версиях работают его собственные кнопки, поля ввода и эффекты нажатия.

Стартовые деньги и лимит супероружия задаёт хост в **Параметрах** комнаты до запуска. Генерал, цвет, команда и старт запоминаются для подключённой игры; занятый или отсутствующий вариант заменяется доступным.

В комнате нажмите ячейку, чтобы выбрать значение. Список открывается на текущем пункте. Стрелки вверх/вниз проходят между страницами, Enter выбирает, Esc закрывает. Основное действие выделено золотом, видны фокус с клавиатуры и переключатели. Тема работает и без Modern UI. Случайные варианты сервер выбирает при общем старте.

**Карта → Старты** выбирает старты; **Карта → Ресурсы** показывает поставленные маркеры складов и вышек. Перетаскивание сдвигает карту, колесо меняет масштаб. **Моя позиция** возвращает к игроку, **Все точки** показывает все маркеры.

Маркеры находятся во вкладке **Generals** творческого инвентаря. Нажмите по стартовому маркеру кнопкой взаимодействия Minecraft, чтобы настроить игрока/NPC, фракцию, команду и сложность. Вышки захватываются исходной способностью Generals. **Generals → Мир и маркеры → Найти маркеры** открывает параметры, заметки, карту, удаление и телепортацию с проверкой прав, в том числе в непрогруженные области. «Назад» и Esc сохраняют изменённые название и заметку с подтверждением сервера. При ошибке черновик остаётся в редакторе; «Не сохранять» позволяет выйти. Лучи маркеров видны в обычном Minecraft. Контуры расчистки видны у всех ближайших загруженных маркеров: синий для старта, зелёный для склада, золотой для нефти. Размер старта учитывает самое большое стартовое здание и его поворот.

ЛКМ по мобу без выбранных вооружённых юнитов показывает его иконку. С вооружёнными юнитами выдаётся обычная атака; Ctrl не нужен.

## Управление техникой

В режиме Minecraft нажмите кнопку взаимодействия по своей технике, чтобы сесть. Сервер проверяет владельца армии.

| По умолчанию | Действие |
| --- | --- |
| WASD | Двигаться относительно камеры |
| Мышь | Навести башню с её исходной скоростью поворота |
| Удержание ЛКМ | Стрелять с исходной перезарядкой оружия |
| Отпускание ЛКМ | Прекратить огонь |
| Shift | Выйти из техники |

Движение, атака и выход используют ваши клавиши Minecraft. В третьем лице камера смещается к плечу, чтобы персонаж не закрывал прицел. Прицел золотой в пределах дальности оружия и оранжевый за её пределами. Дождитесь поворота башни и подойдите на дальность выстрела. Стрелы остаются на юнитах в месте попадания.

Для сбора ресурсов постройте центр снабжения и нажмите ЛКМ по складу выделенным чинуком, грузовиком или рабочим. В новой катке запас восстанавливается.

## Debug меню

В одиночной свободной игре Creative откройте **Generals → Мир и маркеры → Debug меню**: деньги, ранг, все повышения, перезарядка, лечение, туман и музыка. В любой схватке, в том числе против NPC, Debug отключён. Прямые запросы сервер тоже отклоняет. Правила меняет только хозяин мира; на выделенном сервере хозяин комнаты также должен быть оператором. `/zh-debug` есть только в сборках для разработки.

ЭМИ и ECM временно отключают мобов: синий оттенок и оригинальный значок молнии. Настройка **Правила → ЭМИ → Оглушать мобов** управляет ЭМИ/ECM, а **Правила → Мобы → Микроволны оглушают мобов** задаёт действие микроволнового танка отдельно. Слизни нейтральны к армии, пока их не атакуют.

Камера RTS сохраняет высоту над воронками. Чтобы спуститься вручную, продолжайте приближать колёсиком.

Завершайте RTS через меню. F8 меняет только режим камеры. Юниты RTS между запусками не сохраняются; земля Minecraft и маркеры сохраняются.

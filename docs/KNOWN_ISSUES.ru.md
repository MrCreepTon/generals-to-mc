# Ограничения беты

[English](KNOWN_ISSUES.md) · **Русский**

- Только Windows и Fabric. Нужен JAR для точной поддерживаемой версии Minecraft. Linux/Wine пока не поддержаны.
- В 26.3 добавлена защита от редкого вылета JVM при нативной компиляции шейдеров на Windows. Проверки с защитой проходят, но контрольный запуск без неё тоже прошёл; окончательно подтвердить исправление пока нельзя. Обновление Java само по себе не устраняло воспроизведённый сбой.
- Нужны собственные Generals и Zero Hour. Generals без Zero Hour не портирована. Проверены обычная игра и установленная ROTR, но не каждый её юнит и способность. Contra не проверена. Моды с изменениями EXE/DLL требуют отдельной поддержки.
- Часть исходных режимов, моделей, материалов, теней и способностей ещё отличается или отсутствует.
- Сохранение RTS, кампании/Challenge, реплеи, вход и переподключение посреди матча не поддержаны.
- Долгие маршруты через неизвестные чанки, большие области местности, многоуровневая навигация и границы мира требуют дальнейшей работы.
- Наблюдение за NPC без собственной армии, оборона деревни и захват/удержание точек пока не реализованы.
- Два настоящих клиента 26.3 прошли восемь минут с NPC и искусственными 0/100/300/0 мс RTT. Отдельно пройдены пять минут общей симуляции одного клиента с NPC. Более ранние проверки двух клиентов есть для 1.21.4. Внешний выделенный сервер, долгие WAN-матчи, большие армии и полный сетевой прогон каждой версии ещё не проверены.
- Правила огня и разрушений относятся к оружию Generals. Пожары и взрывы Minecraft подчиняются его gamerules.
- Маркеры складов, вышек и стартов сохраняются с миром. Полной палитры зданий и естественной генерации нефтяных вышек пока нет.

Проверки охватывают отдельные сценарии, а не все возможные сбои. Если движок остановился, используйте экран восстановления и журналы в `%LOCALAPPDATA%/GeneralsMinecraft`.
